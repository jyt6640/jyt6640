## 프로젝트 / Projects

**[Knot](https://github.com/woowacourse-teams/2026-knot)**  
지난 회의의 결정 사항을 채팅으로 찾는 서비스입니다.  
A service for finding past meeting decisions in chat.

- PostgreSQL 키워드 검색으로 문서 탐색을 바꿔, 비교 실험에서 첫 응답 시간이 **24.3초에서 3.5초**로 줄었습니다.  
  Switched document retrieval to PostgreSQL keyword search, cutting time to first streamed text from **24.3s to 3.5s** in a benchmark.

**[yANUs Groupware](https://github.com/Yanus306/yanus-groupware-BE)**  
개발 동아리의 일정과 출석을 관리하는 서비스입니다.  
A tool for managing a student development club's schedules and attendance.

- 출석 예외 조회의 SELECT 쿼리를 **요청당 603회에서 2회**로 줄였습니다.  
  Cut attendance exception queries from **603 to 2 SELECTs per request**.

**[Persona Harness](https://github.com/jyt6640/persona-harness)**  
AI 코딩 에이전트에 작업에 맞는 지침을 제공하는 TypeScript CLI입니다.  
A TypeScript CLI that gives AI coding agents task-specific guidance.

- 수정할 파일에 맞는 개발 컨벤션을 골라 전달하고, 계획부터 코드 리뷰까지 작업 순서를 안내합니다.  
  Selects conventions for the files being changed and guides agents from planning through code review.
